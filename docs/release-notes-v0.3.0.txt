okf-cli v0.3.0 — 2026-11-10

本次版本汇总 0.2.0 之后的安全修复、CLI 改进、契约验证与 Skill 更新。

安全与修复

- 统一主仓库与子模块的 Git 远端传输校验，拒绝选项式地址、危险 SSH 主机名、本地路径、file://、ext::、内嵌凭据和控制字符，防止 Git/SSH 参数注入及传输策略绕过。
- 将 LFS 的 incomplete/tmp 暂存目录计入 --max-git-bytes，并在 LFS 拉取前后清理残留半成品，修复暂存区绕过配额的问题。
- bundle add 的本地路径不存在时返回 NOT_FOUND，并明确报告缺失路径。

验证与文档

- 补齐全文搜索、正文上下文的响应 Schema，覆盖来源、索引版本、原文片段、预算、空结果、多包及候选检索；不改变检索行为。
- 增加 CLI 别名、运行目录参数与参数冲突的回归测试。
- 内置 Agent Skill 增加证据引用、冲突呈现、过期内容标记、章节边界、多来源保留和回答前自检规范。
- 同步架构与发行说明。

升级说明

- 相比 0.2.0，正文数据库仍为 v1，候选派生数据仍为版本 2，本版本未引入新的数据格式迁移。
- 从 0.1.0 升级时，继续遵循 docs/releases.md 中的 0.2.0 升级说明。
- 更新内置 Skill 时先安装到新目录，再合并现有定制；skill install 保留防覆盖行为。

发行包

- 提供 Windows x64 MSVC、Linux x64 GNU 和 macOS ARM64 CLI 包，以及内含三平台二进制的独立 Agent Skill ZIP。
- 每个 ZIP 均提供 SHA-256 校验文件；release-set.json 记录来源与包哈希，SHA256SUMS 覆盖发行附件。
- Linux 要求 glibc 2.35 或更新版本，Windows 依赖 VC/UCRT 运行库，macOS deployment target 为 14.0；最低操作系统版本尚未实机验证。
