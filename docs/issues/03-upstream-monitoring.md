## 问题与修复

原基线 `bd9e5376de4505b3693fcb749e9683db9f6ef567` 仍跟踪停止更新的 Google 仓库；发现变化后仅在 JSON 中标记待审查，终端仍打印 `Upstream audit passed`，工作流仅支持手动触发。

现已保留旧快照，新增新官方规范和代表性样例的固定提交及哈希。监测明确区分本地验证、无变化、待审查和检查失败，分别报告规范、样例、布局变化及网络错误；任何变化都不会自动推进基线。
