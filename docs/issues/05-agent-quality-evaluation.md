# 完成可重复的 Agent 消费对照评测，建立答案质量与成本基线

建议优先级：P1。类型：评测 / 产品验证。

## 问题与影响

已有工程验证充分覆盖读取、索引、预算及证据完整性，但不能直接证明 Agent 答案质量。正式 `agent-cli-v1` 重复对照评测尚未完成，当前无法稳定衡量 Skill 或检索策略改动对实际任务效果的影响。

`docs/verification.md` 记录了 9 次独立 Agent 行为冒烟：原始六个任务严格评分为 5/6 完整、11/12 必要事实。记录明确说明没有固定精确模型版本、策略组、三次重复及完整 token/费用统计。这些观察不能外推成通用正确率。

## 建议实施

复用现有隔离准备工具、任务和评分协议。运行前确定模型、重复次数与费用上限；预算未明确时只做评测准备，不启动付费模型调用。

在原有任务之外补充：内容更新后的旧审核、替代概念、紧预算末尾证据、跨包冲突、重复来源、无答案与部分覆盖。对比元数据优先、全文检索及候选策略，保持宿主能力和成本约束可比。

## 验收标准

- [ ] 固定模型标识、CLI 提交、Skill 版本、语料哈希、策略、采样参数与费用上限；无法取得的参数明确记录。
- [ ] 各策略按既有协议完成重复运行，测试任务不向 Agent 暴露预期答案。
- [ ] 保存调用轨迹、最终答案、证据、耗时、披露量及 token/费用；区分准备失败、工具失败和回答失败。
- [ ] 评分覆盖任务完成、必要事实、引用支持、无依据断言、错误信任、冲突保留和合理拒答。
- [ ] 空回答不能仅因没有错误断言被算作成功。
- [ ] 对质量及成本作成对比较，保留失败案例并说明小样本限制。
- [ ] 发布可复核的评测摘要及产物入口，避免证据仅存在于本地临时目录或会话。
- [ ] 依据结果确定后续改进，不把确定性检索通过解释成模型效果通过。

关联：审核时序与格式兼容提供消费语义基线；[有限预算检索](04-budgeted-retrieval.md) 已完成确定性对照，模型任务收益仍需本评测衡量。
