# 改善有限预算检索的证据召回，评估默认候选策略与多包配额

建议优先级：P1。类型：检索质量 / 性能。

本地进展：预算优化与验收已完成。默认保留路径扫描，候选策略继续显式启用；行为见 [候选检索](../cli-contract.md#候选检索)，对照结果与质量门槛见 [有限预算策略对照](../verification.md#有限预算策略对照)，完整实测见 [验收记录](../verification.md#2026-11-27有限预算检索全面实测42)。

## 问题与影响

默认索引查询按路径读取有界前缀。在多包大小不均或关键证据位于路径末尾时，结果会受文件位置影响。覆盖状态虽能诚实报告不完整，但不能帮助 Agent 找到遗漏的关键证据。

当前全文匹配采用查询词全部满足的子串匹配，评分主要为元数据命中 5 分、正文命中 1 分。自然语言长查询、同义表达和跨语言问题的有效性尚需专门测量，不能用精确词任务的通过率推断。

## 基线与实现

- `evaluate_budgets.py` 保留默认路径扫描的有限预算基线。
- `evaluate_budget_strategies.py` 在同一语料、查询和预算下比较路径扫描与候选策略，可传入修改前二进制；报告保存构建和语料哈希。
- 候选枚举预留元数据复核预算，截断列表不排除已有候选，成功调用未用完的额度传给后续包。

短词回退、别名排序偏置和自然语言字面匹配仍有限制；稀有三元组排序、词法排序和查询改写留作独立实验，向量检索不属于本次实现。

## 验收标准

- [x] 固定构建、语料与查询集，记录现有策略基线。
- [x] 覆盖末尾证据、大小不均多包、稀疏筛选、重复来源、中文、短词及自然语言查询。
- [x] 报告正文读取、候选行读取、延迟、索引体积和同步成本；明确行预算不包含所有数据库工作。
- [x] 报告召回、来源覆盖及退化案例，不以增加预算作为优化收益。
- [x] 保留默认路径扫描，记录候选策略继续显式启用的原因。
- [x] 保持原文哈希、字节范围、generation、独立来源及部分覆盖语义。
- [x] 固定回归集具有可执行的质量门槛，不设置机器相关的耗时门槛。
