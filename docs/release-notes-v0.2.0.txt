okf-cli v0.2.0 — 2026-11-04


发行包含 Windows x64 MSVC、Linux x64 GNU、macOS ARM64 CLI 包，以及内含三平台二进制的独立 Agent Skill 包；提供各包 SHA-256、release-set.json 和 SHA256SUMS。

运行环境：Linux 要求 glibc 2.35 或更新版本；Windows 依赖 VC/UCRT 运行库；macOS deployment target 为 14.0。验收环境为 Ubuntu 22.04、Windows Server 2022 和 macOS 15 ARM64；最低操作系统实机验证尚未完成。

### 新增能力

- Git 远端支持私有 HTTPS 凭据与 SSH 传输，增加精确下载字节统计和显式缓存 GC。
- 支持获取并读取 Git 子模块及嵌套子模块内容，下载 LFS 对象并在读取指针时返回真实内容。
- 校验支持图片引用、附件类型和 HTML `id`/`name` 锚点，解码 HTML 实体；报告外部链接引用但不抓取外部内容。
- 增加官方语料验收入口，更新 Agent Skill 命令参考和使用文档。

### 升级注意事项

- 候选派生数据升级为版本 2，正文数据库仍为 v1，响应策略名仍为 `candidates-v1`。升级后对需要候选检索的知识包执行 `okf sync NAME`；旧程序写入索引后需再次同步。
- 已有相对 `file:PATH` 凭据引用不会自动迁移；请按原调用目录确认文件，再将引用改为绝对路径。
- Skill 安装保留防覆盖行为。先安装到新目录，再合并已有定制，确保同时更新 `SKILL.md` 与 `references/cli-workflows.md`。
- 升级前备份运行目录并保留旧二进制；不承诺任意版本之间的数据库兼容。

### 修复与文档

- 补齐元数据搜索结果的响应 Schema，约束卡片和来源字段；增加必填、类型及扩展兼容反例和真实 CLI 响应检查，不改变检索行为。

- 独立 Agent 实测发现 PowerShell 引用参数需加引号，修正 Skill 示例并完成独立复测；记录按需章节读取、证据定位及评分缺口。

- Skill 改为按需加载命令参考，内嵌安装和两类发行包同时携带入口与参考文件，并校验内容一致性及防覆盖行为。

- 逐项核对 21 个业务命令与 40 个长选项，修正文档中的资源数量上限和 Git 配额/GC 范围，补充参数组合、管理操作及功能对照表。

- 将项目说明合并为设计与实现、CLI 使用与校验、验证与评测、安装与发行四份文档，README 统一导航；明确历史证据与当前源码的适用范围。

- 修复子模块/LFS 下载忽略存储配额错误、相对凭据文件路径随工作目录变化的问题；新增绑定保存绝对凭据路径。
- 元数据搜索按全局引用顺序选取结果；实时、全文和候选搜索统一只匹配检索字段值，候选派生版本升级为 2，旧候选数据需重新 `sync`。
- 显式浏览和读取拒绝路径中的目录链接/Junction；HTML 锚点检查不再将其他属性值、注释或脚本文本误认为锚点。
- 统一源码与发行版本能力描述，将 LFS 完整性回归接入交付验收。
- 子模块凭据仅传给相同 HTTPS 主机和端口；保留 SCP 格式地址，仅解析 `./`、`../` 相对地址。
- LFS 缓存读取校验声明长度与 SHA-256；损坏内容和不支持校验的 SHA-1 指针返回完整性错误。
- GC 正确清理旧下载引用，并保护当前绑定及已下载的嵌套子模块；扫描或保护失败时不执行回收。
- 增加真实 HTTPS 凭据隔离、GC 后子模块读取和 LFS 缓存损坏回归。行为与限制见随包 docs/cli-contract.md。
